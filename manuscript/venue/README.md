# Venue layer

`generic.tex` is a readable writing/review format. It is **not a submission
template** and must not be presented as matching any venue's requirements.

Once the target venue is known, add the appropriate file here, for example
`acm.tex`, `ieee.tex`, `springer.tex`, or `elsevier.tex`. Do not download or
guess a template during the venue-neutral writing phase. Before submission,
check the venue's official current author instructions and migrate the document
class, front matter, bibliography style, and page-dependent layouts there.

Venue-specific commands such as `\affiliation`, `\ccsdesc`,
`\IEEEauthorblock`, and `\institute` belong in this layer or in metadata—not in
`sections/*.tex`.
