2. 在私有目录填写作者信息表。
3. 登录投稿系统确认实名/匿名、MathType和图形要求。
4. 如需 MathType，在私有 Word 副本中转换并完成99项核对。
5. 补齐真实元数据，使用 Microsoft Word 导出并逐页检查。
6. 依投稿系统检查表人工录入、上传、预览和提交。
