## 4. 由实际参考图得出的图2视觉决定

1. 时间向下：P1图2/8及H1/H2均如此。8.2cm内横排7个执行阶段及完整接受参数会压缩文字，因此采用纵向事件轴和侧边依赖线。
2. 科学内容只来自本项目模型、存在性性质和独立复核graph。外部论文只提供图形组织参考。
3. 以四个动作事件和 s、b、r₁、r₂ 为主层；规则名为次级说明。两次收集仅显示规则和槽位数据，不冒充动作事实。
4. 一个 Out(E) 公开节点分支到两个槽位；同一 E=(A,oid,m) 在槽位1/2原样显示。重复发生在候选条目投递层。
5. 一个持久来源事实节点，以同源的两条虚线接入两次处理；虚线语义为本文明确定义，不继承参考图的分支语义。
6. 同一批次边界包围收集、准入和接受；两个接受事件保留完整相同参数，仅时间不同。
7. 白底、黑白/浅灰、0.35pt框线、0.45pt箭头、1pt圆角，与冻结图1协调；不使用任何图标。
8. 中文短图题采用“无互异约束模型中的重复接受可达执行”。图注附近说明重构属性及仅显示相关事件投影。
