\subsection{放宽参与方条件后的重复接受}
\label{subsec:relaxed-results}

% P31-1
在表\ref{tab:admission-configurations}的放宽配置中，正常获接纳路径的存在性验证通过（\path{normal_relaxed_batch_exists}）：模型能够经过批次接纳并到达后续接受事件。这一结果排除了生命周期无法运行的情形，但本身不要求不同参与方，也不用于证明目标参与方关系。

% P31-2
核心问题是：一个精确发送来源能否在同一批次和接收方上下文中支持两次不同接受？对应的存在性验证通过（\path{one_send_two_accepts_exists}）。按式\eqref{eq:abstract-entry}的条目记号，见证中的两个槽位收集同一个$(A,\oid,m)$精确元组；它不是由同一参与方的两个不同消息构成的批次。根据模型及导出见证，相关事件可重构为
\begin{equation}
  \begin{aligned}
    &\mathsf{Send}(A,\oid,m)@s,\\
    &\mathsf{BatchReceive}(\mathit{bid},\mathit{rst})@b,\\
    &\mathsf{ReceiverAccept}(A,\oid,m,\mathit{bid},\mathit{rst})@r_1,\\
    &\mathsf{ReceiverAccept}(A,\oid,m,\mathit{bid},\mathit{rst})@r_2,\\
    &s<b<r_1<r_2.
  \end{aligned}
  \label{eq:relaxed-duplicate-witness}
\end{equation}

% P31-3
式\eqref{eq:relaxed-duplicate-witness}保留了一个来源、一次批次接纳和两次接受之间的关系。两个接受事件的全部坐标均相同，但$r_1<r_2$表明它们是不同的事件发生。存在性性质还要求，所有匹配该$(A,\oid,m)$的发送事件均为$s$处的同一个事件；因此，两次接受并非分别对应两个匹配发送。这个唯一性要求只针对所显示的精确元组，不排除执行中出现其他坐标的无关发送，故核心事件链不列出此类事件。

% exact-origin duplicate acceptance trace in relaxed admission

% P31-4
见证中的重复使用发生在批组成与接纳环节：同一个已暴露条目占据两个槽位，批次接纳后，两个处理步骤分别匹配同一持久来源事实并记录接受。这将“候选条目可以重复”的组合选择连接到实际可达的两个接受事件，而不只是说明接纳条件在语法上允许坐标相等。由于两个位置具有相同参与方投影，这条执行也给出了研究问题RQ1所关注的一类重复参与方组合，并对RQ2给出肯定的存在性回答。

% P31-5
与该存在性结果对应，作用域内发生注入性被反例否定（\path{receiver_accept_injective}）。按照表\ref{tab:verification-property-semantics}的语义，式\eqref{eq:relaxed-duplicate-witness}满足同一匹配发送早于两次同坐标接受的前件，却具有$r_1\neq r_2$。存在性验证从“有一条这样的执行”给出见证，全迹性质则由这类执行推翻；二者是同一重复接受形状的两种验证表述，不构成两个独立发现。

% P31-6
与此同时，精确来源对应验证通过（\path{receiver_accept_has_send}），两个接受都能够追溯到更早的匹配$\mathsf{Send}(A,\oid,m)$。因此，反例并非无来源的凭空接受，而是合法来源条目在同一批次中被重复使用；正常路径可达、来源对应成立和注入性失败共同确定了这一解释。该见证属于放宽不同参与方接纳条件后的两槽抽象，并不是满足K-Waay原有不同参与方条件的完整协议攻击。

\subsection{消息级限制的替代性}
\label{subsec:message-results}

% P32-1
消息级配置首先成功维护了其直接约束的消息区分性质，相应全迹验证通过（\path{accepted_batch_has_distinct_messages}）。具体而言，同一$(\mathit{bid},\mathit{rst})$中的两个不同\receiveraccept 事件具有不同消息坐标。该结果是在接受事件上检查消息区分，并未将消息比较替换为参与方比较；表\ref{tab:identity-coordinate-map}所区分的两个坐标在这里仍承担不同作用。

% P32-2
作用域内发生注入性在该配置中同样验证通过，精确来源对应也继续成立。因而，第\ref{subsec:relaxed-results}节中同一个精确发送来源支持两个同批接受的形状已被排除，而每个接受事件仍具有匹配的发送来源。消息区分与发生注入性并非同一个性质：前者比较不同接受事件的消息坐标，后者限制一个精确来源对应的接受发生数。这里分别报告两项全迹结果，以免将消息级控制的成功直接等同于目标参与方关系成立。

% P32-3
决定替代性结论的是同一参与方、不同消息批次的可达性，该存在性验证通过（\path{same_party_different_messages_batch_exists}）。机器见证包含同一参与方$A$的两个条目$(A,\oid_1,m_1)$与$(A,\oid_2,m_2)$，满足$\oid_1\neq\oid_2$和$m_1\neq m_2$。二者分别具有匹配的$\mathsf{Send}(A,\oid_1,m_1)$与$\mathsf{Send}(A,\oid_2,m_2)$来源，随后进入同一$(\mathit{bid},\mathit{rst})$批次，并产生两个不同的接受事件。

% P32-4
这一见证的两个发送事件均早于批次接纳，接纳又早于依次发生的两个接受事件。各条目使用自己的匹配来源完成处理，因此没有重用同一个精确元组；保留下来的相等关系仅在参与方坐标上。与放宽配置相比，这里精确来源不同、发送发生不同、消息不同，却仍有$A_1=A_2$。消息级条件和来源匹配在同一条执行中均得到满足，重复参与方组合仍能到达两个接受事件。

% P32-5
因此，非替代性结论不只来自“消息不同不代表参与方不同”的逻辑观察。第\ref{subsec:research-questions}节提出的替代性问题还要求确认该组合能否通过共同生命周期；上述机器见证补足了这一可达性证据。它与消息区分、发生注入性的全迹验证结果同时存在，直接表明这两项性质成立仍不足以保证式\eqref{eq:distinct-party-objective}所要求的参与方关系。

% P32-6
作为支持结果，消息相等时的拒绝分支存在可达执行（\path{repeated_message_rejection_exists}验证通过），这里只据此报告分支可达性，不推断所有重复消息都会最终被拒绝。

% P32-7
综上，消息级配置同时实现消息区分和作用域内发生注入性，但仍允许同一参与方的不同合法发送条目进入同一批次。对RQ3而言，替代性检验的失败点在于参与方关系仍可被违反，而不是消息级配置未能维持自身性质；消息与发送发生层面的这两项成功不能替代参与方级关系。

\subsection{参与方级条件下的性质验证}
\label{subsec:party-results}

% P33-1
参与方级配置作为正控制，在接纳时直接要求$A_1\neq A_2$。相应参与方区分性质的全迹验证通过（\path{accepted_batch_has_distinct_parties}）：同一$(\mathit{bid},\mathit{rst})$内的两个不同\receiveraccept 事件具有不同参与方坐标。这里验证的是式\eqref{eq:distinct-party-objective}对应的目标投影，其他条目坐标不被用作参与方的替代标识。

% P33-2
这一结果同时具有规则层与迹性质层的依据。接纳分支记录参与方不等关系，并由模型的不等式约束排除相等参与方；全迹结果进一步在后续接受事件上确认该关系。前者说明接纳选择受什么条件限制，后者说明可达接受事件满足什么性质，两者作用不同。正控制由此将接纳处的目标坐标限制与接受处的参与方区分联系起来。

% P33-3
有效不同参与方批次的存在性验证也通过（\path{distinct_party_batch_exists}）。见证包含两个不同参与方及各自的合法发送来源，两个发送事件均先于同一次批次接纳，随后产生依次发生的两个接受事件。该见证表明接纳并非只能停留在条件判断处，有效条目能够完成后续处理，从而排除了“全部批次均被拒绝，性质因无接受事件而真空成立”的解释。

% P33-4
作为支持性质，精确来源对应与作用域内发生注入性均验证通过，说明有效路径上的来源与发生关系和目标参与方性质相容。同参与方拒绝分支也存在可达执行（\path{same_party_rejection_exists}验证通过），但该性质没有将此前发送的具体条目绑定到最终被拒绝的候选元组，故不能据此断言这些条目或任意同参与方输入都会最终被拒绝。

% P33-5
参与方级正控制的主要证据因而是目标性质与有效批次可达性的配合：前者验证获接纳条目的参与方区分，后者确认这种区分并非通过消除全部有效行为取得。在当前两槽抽象中，直接约束参与方坐标能够维持目标关系，同时有效的不同参与方批次仍然可达。
